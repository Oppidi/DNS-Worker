## Domain Blocking & Filtering Engine

**DNS Worker** acts as a Protective DNS (domain-blocking system) that filters traffic at the resolution layer before network connections are established:

- **Ad & Telemetry Filtering**: Blocks banner ads, trackers, and OS diagnostic telemetry across routers, phones, tablets, and smart TVs without client extensions.
- **Threat Interception**: Stops malware distribution hosts, ransomware callbacks, phishing domains, cryptominers, and botnet C2 domains at the DNS layer.
- **Compact Bloom Filter Architecture**: Separates exact domain and `||` wildcard subdomain matching while maintaining low memory usage even inside 128 MB edge isolates.
- **Flexible Rule Governance**: Supports preset public blocklists (OISD Big, AdGuard Base, HaGeZi Multi PRO++, StevenBlack Hosts) alongside custom exact/wildcard/regex rules and DNS rewrites.
- **Real-Time Query Inspection**: Shows permitted, blocked, and rewritten queries with per-domain list checking and a detailed audit drawer.
