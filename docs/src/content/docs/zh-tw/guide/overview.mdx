## 何為 DNS Worker？

**DNS Worker** 是一套注重隱私保護的**保護性 DNS（域名攔截系統）**。它在網路請求的解析階段直接阻斷廣告、行為追蹤、釣魚網站、惡意軟體、挖礦指令碼及殭屍網路（C2）域名，在 TCP 握手或 TLS 協商建立前終止異常連線。

系統支援訂閱常用外部過濾列表並結合本地自定義規則進行裁決，可按裝置或使用場景劃分為多個獨立策略配置（Profile），同時提供加密 DNS 傳輸、瀏覽器本地查詢分析及後量子端到端加密日誌審計能力。

## 協議與功能特性

### 1. 全協議棧覆蓋
* **傳統 UDP 53 (RFC 1035)**：相容傳統路由器、區域網裝置以及系統底層網路設定。
* **加密 DoT 853 (RFC 7858)**：基於 853 埠的高效能加密傳輸，相容 DoQ 極速握手，支援 TLS SNI 多接入點分流（`<profileKey>.dns.example.com`），原生契合 Android 9+ 私有 DNS。
* **加密 DoH (RFC 8484)**：全面相容 HTTP/2 與 HTTP/3 (Alt-Svc) 的安全傳輸協議，適用於主流現代瀏覽器。
* **加密 DoQ (RFC 9250)**：基於 QUIC 協議的高效能 DNS，具備 0-RTT 極速握手並徹底消除隊頭阻塞。
* **ECH 與 DDR (RFC 9460)**：廣播加密客戶端問候（ECH）與專用解析器自動發現（DDR）記錄。

### 2. 域名攔截與過濾引擎
DNS Worker 在 DNS 解析階段阻斷廣告、跟蹤器、釣魚網站、惡意軟體、挖礦指令碼、系統遙測及殭屍網路 C2 域名，在建立 TCP / TLS 連線前攔截風險請求（[檢視規則與架構詳解](/DNS-Worker/zh-tw/filtering/rules/)）：
* **分層混合匹配架構**：結合**雙態字首布隆過濾器**（區分精確域名與 `||` 泛子域，萬分之一誤報率基線）、記憶體散列表 `@@` 白名單例外回溯、`$dnsrewrite` 重寫與頂級域名索引的正則/複雜萬用字元池（受 `MAX_REGEX_RULES` 上限約束），可在資源受限環境中穩定處理數十萬條規則。
* **多格式語法與自定義規則**：相容 Adblock Plus 語法（`||domain^`、`@@||`、`$dnsrewrite`、`/regex/`）、Hosts 檔案及純域名列表；預置常用公開黑名單源並支援全域性 URL 去重與基於 HTTP `304` 的增量同步，同時支援本地配置的白名單（`ALLOW`）、黑名單（`BLOCK`）與重定向規則（`REDIRECT`）。
* **三級列表分層與確定性仲裁**：支援 **Profile 級（配置級）**、**User 級（使用者級）** 與 **System 級（系統級）** 三層規則管理（支援單配置覆寫停用及同名 URL 聯動停用）；衝突裁決順序明確：本地規則（`ALLOW > REDIRECT > BLOCK`）高於外部訂閱列表（`@@ 放行 > $dnsrewrite > 攔截`）。
* **可選攔截響應與單域排查**：支援按 Profile 配置 `Zero IP`（`0.0.0.0` / `::`）、`NXDOMAIN`、`NODATA` 或自定義攔截 IP；列表詳情內建基於緊湊過濾器的單域名命中測試與一鍵放行，配合查詢日誌抽屜追溯具體命中來源。

### 3. 本地優先架構 (Local-First)
依託瀏覽器內嵌的 WebAssembly SQLite 與 OPFS 技術，在前端實現 0ms 閃電級的日誌篩選與多維圖表分析，無需消耗服務端資料庫讀取額度。

### 4. 後量子零知識端到端加密 (PQC E2EE)
採用 NIST FIPS 203 **P256-MLKEM768** 混合格密碼體系，結合硬體通行金鑰（WebAuthn）授權。服務端僅儲存不可逆密文，唯有使用者授權裝置方可完成解密。

## 雙引擎架構

同一套域名過濾與解析核心支援以兩種執行時形態部署（詳見 [系統架構](/DNS-Worker/zh-tw/architecture/overview/)）：

1. **☁️ Serverless 邊緣模式 (首選推薦)**：
   運行於遍佈全球 300+ 邊緣節點的 Cloudflare Workers 與 Cloudflare D1 分散式 SQL 資料庫之上，享有零維護成本、全網 Anycast 智慧就近排程以及極速邊緣響應。
2. **🖥️ Serverfull 獨立服務模式 (自由自建)**：
   擺脫對任何公有云廠商的依賴，在自有 VPS、家庭主機或實體伺服器上執行。依託 Node.js / Bun 原生 `node:sqlite`，原生提供經典 UDP 53、DoT 853（支援 TLS SNI 多接入點分流）以及一體化 Web 管理面板與 DoH。
