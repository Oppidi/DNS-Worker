## 域名攔截與過濾能力

**DNS Worker** 作為保護性 DNS 解析系統，在網路通訊建立前的域名解析階段提供流量過濾與安全審計：

- **廣告與系統遙測過濾**：在路由器、移動裝置與桌面端統一遮蔽橫幅廣告、追蹤域名與作業系統診斷遙測，無需安裝客戶端擴充套件。
- **惡意域名攔截**：阻斷已知惡意軟體分發節點、勒索軟體回撥、釣魚域名、挖礦指令碼及殭屍網路（C2）控制域名。
- **緊湊布隆過濾器引擎**：區分精確域名與 `||` 泛子域規則，在 128 MB 等受限執行環境下併發評估數十萬條過濾規則。
- **多層級規則與重寫體系**：預置公開規則源（OISD Big、AdGuard Base、HaGeZi Multi PRO++、StevenBlack Hosts），支援本地高優先順序放行/攔截規則及區域網 DNS 重寫。
- **即時查詢日誌與規則排查**：清晰展示放行、阻斷與重寫狀態，支援單域名規則命中測試與日誌詳情抽屜審計。
