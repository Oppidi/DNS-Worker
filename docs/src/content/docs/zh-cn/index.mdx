## 域名拦截与过滤能力

**DNS Worker** 作为保护性 DNS 解析系统，在网络通信建立前的域名解析阶段提供流量过滤与安全审计：

- **广告与系统遥测过滤**：在路由器、移动设备与桌面端统一屏蔽横幅广告、追踪域名与操作系统诊断遥测，无需安装客户端扩展。
- **恶意域名拦截**：阻断已知恶意软件分发节点、勒索软件回调、钓鱼域名、挖矿脚本及僵尸网络（C2）控制域名。
- **紧凑布隆过滤器引擎**：区分精确域名与 `||` 泛子域规则，在 128 MB 等受限运行环境下并发评估数十万条过滤规则。
- **多层级规则与重写体系**：预置公开规则源（OISD Big、AdGuard Base、HaGeZi Multi PRO++、StevenBlack Hosts），支持本地高优先级放行/拦截规则及局域网 DNS 重写。
- **实时查询日志与规则排查**：清晰展示放行、阻断与重写状态，支持单域名规则命中测试与日志详情抽屉审计。
