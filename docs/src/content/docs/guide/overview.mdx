## What is DNS Worker?

**DNS Worker** is a privacy-focused **Protective DNS (domain-blocking system)**. Operating at the DNS resolution layer before a TCP handshake or TLS negotiation begins, it blocks advertisements, trackers, phishing domains, malware distribution hosts, cryptominers, and botnet C2 domains.

It supports subscribing to public filter lists alongside local custom rules, separating policies per device or use case via Profiles, and providing encrypted DNS transport, browser-local query analysis, and post-quantum end-to-end encrypted audit logs.

## Protocols & Capabilities

### 1. Full-Stack Protocol Coverage
* **Classic UDP 53 (RFC 1035)**: Standard DNS resolution for routers, LAN devices, and system-wide configurations.
* **DoT 853 (RFC 7858)**: Encrypted DNS over dedicated port 853 with DoQ compatibility and TLS SNI profile routing (`<profileKey>.dns.example.com`), natively compatible with Android 9+ Private DNS.
* **DoH (RFC 8484)**: Fully compatible with HTTP/2 and HTTP/3 (Alt-Svc) for secure, low-latency transport across modern web browsers.
* **DoQ (RFC 9250)**: Encrypted DNS over QUIC with 0-RTT handshakes and zero head-of-line blocking.
* **ECH & DDR (RFC 9460)**: Broadcast Encrypted Client Hello parameters and outer SNI, paired with Discovery of Designated Resolvers (DDR).

### 2. Domain Blocking & Filtering Engine
DNS Worker blocks advertisements, trackers, phishing domains, malware hosts, cryptominers, OS telemetry, and botnet C2 domains at the DNS resolution layer before TCP or TLS connections are established ([Filtering & Blocklists](/DNS-Worker/filtering/rules/)):
* **Tiered Hybrid Match Engine**: Combines a **Dual-State Prefix-Encoded Bloom Filter** (distinguishing exact domains from `||` subdomain wildcards at a `0.0001` target false-positive rate), an in-memory Hash Set for `@@` allowlist exceptions with parent-label walk fallback, `$dnsrewrite` rules, and a TLD-indexed wildcard/regex pool (`MAX_REGEX_RULES` bounded)—handling hundreds of thousands of rules within tight edge memory budgets.
* **Multi-Format Syntax & Custom Rules**: Parses Adblock Plus rules (`||domain^`, `@@||`, `$dnsrewrite`, `/regex/`), Hosts files, and plain domain lists; includes preset public blocklists with deduplicated compilation and conditional HTTP `304` incremental sync, alongside per-profile local `ALLOW`, `BLOCK`, and `REDIRECT` rules.
* **Three-Tier Governance & Deterministic Arbitration**: Organizes subscriptions into **Profile-level**, **User-level**, and **System-level** tiers with per-profile disable overrides and linked duplicate-URL toggling. Precedence is deterministic: local rules (`ALLOW > REDIRECT > BLOCK`) override external lists (`Allow (@@) > Rewrite ($dnsrewrite) > Block`).
* **Configurable Block Actions & Domain Testing**: Supports per-profile `NULL_IP` (`0.0.0.0` / `::`), `NXDOMAIN`, `NODATA`, or custom block IP responses, together with single-domain testing against compiled filters, one-click allow exceptions, and query-log rule inspection.

### 3. Local-First Architecture
Using embedded in-browser SQLite (WebAssembly + Origin Private File System), query log filtering and multi-dimensional analytics render instantly in 0ms without exhausting server database read quotas.

### 4. Post-Quantum Zero-Knowledge E2EE
Implements NIST FIPS 203 **P256-MLKEM768** hybrid lattice cryptography, protected by hardware Passkeys (WebAuthn). Persistent storage holds only irreversible ciphertexts; decryption takes place strictly on authorized user devices.

## Dual-Engine Architecture

The same domain-filtering and resolution core runs seamlessly across two deployment runtimes ([Explore System Architecture](/DNS-Worker/architecture/overview/)):

1. **☁️ Edge Serverless Mode (Primary / Recommended)**:
   Deploy across 300+ global edge locations on Cloudflare Workers and Cloudflare D1 distributed SQL database. Benefit from zero server maintenance, global Anycast acceleration, and sub-millisecond edge latency.
2. **🖥️ Standalone Server Mode (Serverfull Self-Hosted)**:
   Run completely independent of Cloudflare on your own VPS, home server, or bare-metal Linux/Windows host. Powered by Node.js / Bun built-in `node:sqlite`, it natively serves classic UDP 53, DoT 853 (with TLS SNI profile routing), and Web Dashboard / DoH.
